off-white quente `#F8FAF7`, verde-profundo biotech `#071E22`, acento teal `#13A7A5`,
lima `#B7E36D`, tipografia **Inter** (texto) + **Manrope** (display) — fontes
embarcadas como assets (woff2 latin) por causa do CSP.

Duas paletas em `about.json`: **Revivah** (clara, padrão) e **Revivah Escuro**
(modo escuro automático).

## Instalar / atualizar

Admin → Personalizar → Temas → Instalar → "De um repositório git":
`https://github.com/aplopes-dev/comunidade-tema`

Atualizações: commit aqui → admin → tema → "Verificar atualizações".
